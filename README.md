# Weekly Plate

Dinner planning for the whole week: a plan that fits your home (picky kids,
tight budget, cook once a week, 20 minutes a night), an automatic shopping
list, and a community of cooks you can follow.

| Folder | What it is |
| --- | --- |
| `backend/` | Python (FastAPI) API, Supabase database schema and tests. See `backend/README.md`. |
| `prototype/` | Clickable prototype of the app in Hebrew, English and Russian. Open `prototype/index.html` in a browser. |

The phone app will be built in React Native (Expo) on top of the backend.
